# Bloxy Rivals

*jA modern, modular HTML5 canvas game**

Browser game with comprehensive refactoring for scalability and maintainability. Featuring dynamic player movement, multiple characters, boss battles, and responsive design.

## Status
Complete. Built as a browser gaming experiment.

*"Built by Jmão Caldas | joaoccaldas@gmail.com"**
## Lineage

This repository is part of the Bloxy Rivals evolution. It shares substantial code ancestry with `bloxyrivals2` and is preserved as an **ITERATION** so the development path remains inspectable.

## Project context

This is a personal, self-directed learning project by João Caldas. I learn game development and software engineering by building playable systems, studying failures, refactoring experiments, and comparing different approaches.

AI tools are used extensively during research, design, coding, debugging, testing, asset ideation, and documentation as part of that learning process. AI-generated suggestions are treated as inputs to review, not proof of correctness. Gameplay behavior, persistence, security/privacy boundaries, and technical claims should be tested and documented.

## Canonical lineage decision

The 2026-09-27 repository comparison identifies this repository as the **canonical candidate** for future Bloxy Rivals work.

Evidence:
- compared with `bloxyrivals2`, 72 byte-identical files were reorganized into clearer `src/`, `managers/`, `public/`, and `config/` locations;
- `bloxyrivals2` has only a handful of unique asset-name variants, while this repository contains the structured equivalents plus additional assets;
- compared with `bloxy1`, this repository contains later gameplay systems such as ranking, power-ups, game modes, profiles, boss battles, abilities, rewards, shop systems, and expanded assets;
- its default HTML entry references committed modules correctly.

The other repositories should remain available as historical iterations until links, deployments, and any unique assets are reviewed. No history deletion is required.
